旧版 4 个痛点：
1. 写死 archived = false，已归档任务彻底无法搜出；
2. 输入时被 .searchSuggestions 遮挡，必须多按一次回车才出结果；
3. 仍用纯文字 SessionRow，无 Agent 图标、无关键词高亮、无长按 Git 透视卡；
4. 首屏被 4 行大状态入口占满，却无法按项目 / Agent 筛选。
💡 交互提示：可直接打字检索 · 点上方筛选胶囊 · 长按任务行（或点右侧 ⋯）弹出 iOS 透视预览卡
改进 1 · 补齐盲区 + 精简必要筛选

单排横向胶囊栏：项目 · Agent · 状态 · 含已归档

去掉占半屏的静态「按状态搜索」分组，浓缩为搜索框下方单排轻量胶囊（多台电脑时自适应出现「环境」）。补齐「含已归档」开关，彻底解决已归档任务在 iPhone 上搜不到的问题。

改进 2 · 零遮挡实时反馈

去掉 .searchSuggestions 遮挡，边输边出高亮结果

不再用系统补全列表盖住页面逼用户多按一次回车；每敲一个字实时过滤任务，并用柔和强调色高亮命中的标题、项目、Agent、分支名或错误/进展摘要。

改进 3 · 与新版侧栏同源

统一 AgentLogo 流光环 + 状态胶囊 + Git 交付印记

替换老旧纯文字 SessionRow，与侧边栏 MenuSessionRow 保持一致：运行中展示品牌蓝流光环，右侧展示语义状态胶囊与已推送/已合并图标。

改进 4 · 桌面端右栏预览的 iOS 原生承接

长按（或点 ⋯）弹出 SessionGitPreviewCard + 快捷操作

手机窄屏不做拥挤双栏，直接复用 iPhone 现成的长按预览机制，展示完整标题、待回答/报错摘要、Git 分支与 +ins/−del 方块条，并附带打开、置顶、拷贝 ID、归档快捷菜单。
