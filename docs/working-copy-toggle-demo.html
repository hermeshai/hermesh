工作目录：点一下直接切换（Mac & iPhone 设计对齐）

「当前目录」与「独立 worktree」只有两个互斥状态。去掉两项下拉菜单、改为单击 / 点按直接切换后，操作从「点开菜单 → 找另一项 → 再点一下」缩成一步，旁边紧挨着的分支按钮也会实时在 main 与 基于 main 之间联动。下面在真实比例的 Mac 与 iPhone 输入框上对比三种方案，每个按钮都能直接点、悬停（Mac）或长按/右键（iPhone）。

为什么提示图标推荐「⇄」而不是「↻」或「⌄」？

  • ⌄（下箭头）：代表展开下拉菜单，和右边的分支菜单撞车，点了直接变字会像菜单坏了。
  • ↻（循环箭头）：跟在「📁 当前目录」后面极易看成「刷新目录」。
  • ⇄（双向互换）：语义明确是「两态对调」，与右边分支的 ⌄ / › 一眼区分（底部工具栏可切换三款图标直观对比）。

去掉下拉菜单后，原来的两句解释放哪？

  • Mac（有指针）：悬停时浮出轻量提示，写出当前含义与点击结果（如「直接在项目目录里修改 · 点击切为独立 worktree」）。
  • iPhone（无悬停）：点一下秒切 + 轻触感震动；长按胶囊弹出原生 Context Menu 展示两项完整说明（底部也可开关「点按时浮现 1.6s 轻提示」对比体感）。

无障碍与键盘支持（实现时一并补齐）

  • 语义角色从菜单按钮改为双态切换按钮，读屏直接播报当前值与「点按切换工作目录」。
  • 右侧分支按钮保持不变（仍可点开搜分支、开「从远程开始」），Demo 里点分支也能预览联动效果。
