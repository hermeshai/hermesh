会话「思考中」实时思维链预览 · Mac & iPhone 交互原型 参考 finxwork LiveThinking · 结束即消失

只在 Provider 编码会话处于「思考中」状态时，在底部工作行下方展示最新 3 行实时思维链（新词从底部涌入，超出 3 行时顶部柔和渐隐）；点击「思考中…」可原位展开完整思维链（支持滚动与选字，展开默认吸底、上滑暂停吸底）。思考一旦结束转为工具或回复，整块思维链立即消失，不在历史对话中留痕。

1. 默认 3 行滚动窗 + 顶部渐隐

与 思考中… 正文严格左对齐（x=26px），max-height: 60px（3 行），底部对齐让新文字自然上推；超出 3 行时加顶部 24px 透明渐隐遮罩，未满 3 行时保持边缘清晰。

2. 点击展开全文 + 智能吸底

有思维链正文时右侧出现 chevD 箭头，点击即可展开至最大 280px（iOS 220px）滚动查看全文；展开后继续流式增长会自动吸底，用户手动上滑即暂停吸底。

3. 退化与退场规则

若 Provider 未吐出正文（如 redacted_thinking / Codex 无 summary），自动隐藏箭头与下方区域退化为纯「思考中…」；有 TodoSpine 时嵌入当前步骤下方；思考结束即消失。
