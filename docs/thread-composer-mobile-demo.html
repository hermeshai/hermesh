改了什么

  • 默认收起。没点输入框、框里也没东西时只有一行：＋、文字、发送键；模型、权限模式不再常驻，初始页只剩中间的问题。
  • 点输入框展开。框拉高到两三行，底部一行：左边 ＋ 和模型，右边发送（运行中多一个停下）。有文字或附件时失去焦点也保持展开，空了才收回一行。
  • ＋ 改成底部抽屉。权限模式只在这里，框上不显示。上面两格「照片」「文件」，下面「权限模式」四档（带说明，超过上限的置灰并写原因），选完不关，点空白处收起。「先出方案」去掉了。
  • 工作目录移到框上方。从框下面那行挪到框的左上角，只有 git 仓库的项目才出现，和现在一样。会话中这里是只读的「work-mac · fresh-app」。
  • 新增：工作目录和分支分成两个按钮（参考你截的图）。
    左边「当前目录 / 独立 worktree」：在哪里改，菜单两项。
    右边是分支，点开一个面板：独立 worktree 时标题「基于分支」，从哪个分支新开（默认是仓库的默认分支，如 main），可以打开「从远程开始」先取回远程最新；当前目录时标题「在哪个分支上工作」，默认是已签出的分支，选别的会在开始前把目录切过去（有没提交的改动时不能切）。
    列表：已签出的在最前，标「当前」；默认分支标「默认」；被别的 worktree 签出的标「worktree」（当前目录模式下不能选）。上面有搜索。会话自己的 hermesh/… 分支不列。
  • 思考强度单独一个按钮。在框底部模型按钮旁边，点一下弹出菜单（档位取自所选模型），不用再进模型面板。模型没有档位时这个按钮不出现。
  • 模型面板改成竖排。去掉横向的供应商胶囊：能用的供应商按组竖着排（组头是图标和名字，未登录写在组头上，照旧能选），每行一个模型，选中的只有一个勾，不再写强度。未安装、已停用的供应商不再出现。搜索照旧。思考强度不再放在面板里。
  • 换模型时新模型没有原来的强度，照旧提示一次改成了什么（现有文案）。
会话页
  • 同一个输入框。收起时一行：＋、文字（「继续聊…」，运行中是「继续说，会排到下一轮…」）、运行中的停下、发送。点进去展开，底部一行和新会话一样：＋、模型、思考强度、停下、发送。会话中途换模型、强度、权限模式，照旧从下一轮起生效。
  • 框下面那行去掉。「work-mac · fresh-app」标题下面已经有（「你 · work-mac/fresh-app」），不再重复；模型和权限模式进了框里。
  • 框上方只放待处理的。从上到下：Agent 等你回答的审批卡片（和现在一样）、排到下一轮的消息（收进一张卡片，卡片头写「排到下一轮 · 条数」，这是新加的一行字；每条照旧「立即插入引导」或移除）、「离线排队中」。都没有时框上方是空的。
  • 归档后照旧没有输入框。
分支要补的后端
  • 已有：本地分支和签出的分支（机器的「浏览文件夹」）；worktree 从指定分支开（workspace.base_ref）。
  • 要补：列分支时多说两件事，哪个是默认分支（origin/HEAD）、哪些被别的 worktree 签出了，都是读 .git 里的文件，不起 git 进程。
  • 要补：「从远程开始」，开 worktree 前先 git fetch 这个分支，再从 origin/… 开。
  • 要补：当前目录模式选了别的分支时，开始前在项目目录里切过去；目录不干净就拒绝并写原因，不替你 stash。
  • 新会话默认从默认分支开，现在是从签出的分支开（项目基准分支默认 HEAD），这是一处行为变化。
没变的

中间的「要在 fresh-app 里做什么？」和环境菜单、项目菜单；发送、排队、停下的规则；附件上传方式。Mac 端这次没动，你看完 iPhone 的再决定要不要对齐。
