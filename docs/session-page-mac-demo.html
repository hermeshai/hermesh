会话页 · Mac 原型

两处会话页（SessionPage、ThreadPage）共用同一套对话行；和 iPhone 版同一套规则

Mac 上改什么

1 · 来源：Agent 派来的活加角标

现在 Mac 上的用户气泡对谁都不显示来源，Her 派的活和你自己发的一模一样，只能去信息面板里看「发起」。新版和 iPhone 一致：

  • 你发的：蓝色气泡，什么都不加
  • Agent 派的：灰色气泡，左上角压它的头像（Her 是小猫，授权 Agent 用它自己的 logo，没有 logo 的用首字母）
  • 鼠标悬停时，气泡下方现有的时间和拷贝那一行，前面多一个名字：「Her 派的活 · 今天 00:52」

一个任务可以中途换人说话（Her 派的，你又插了一句），所以按每一轮标，不按整个任务标。

2 · 去掉结尾那句话

「这一轮做完了。你 再发消息时，会在这个任务里接着做。」整行删除，两处会话页都删。进行中的「思考中 / 处理中」那行保留。

3 · 顶栏不动

Mac 的标题在工具栏左侧，信息面板用右上角的按钮开关（⌥⌘0），这是 Mac 上的常见做法，没有照搬 iPhone 的胶囊。唯一的变化：老会话的顶栏现在只有标题，补上和新会话一样的 环境 · 项目，两处一致。

想和你确认的
  • 悬停那行加名字，你觉得有必要吗？不加的话，看名字就只能靠认头像，或者打开信息面板。
  • 被打断时那句「你打断了这一轮。任务还在，你 再发消息就会接着做。」两端都还在，要不要缩成「你打断了这一轮」？
