# 冷启动与账号：产品需求

> 状态：已实施，2026-11-25（实施记录见 cold-start-tech.md §8）。
> 原型：[cold-start-demo.html](cold-start-demo.html)（墨黑，已锁定）。
> 技术方案：[cold-start-tech.md](cold-start-tech.md)。
> 范围：桌面端（macOS、Windows、Linux）。iPhone 和命令行不在本期。

本文与原型一一对应。原型里所有文案、尺寸、颜色、时长都以本文为准；原型里只是示意、沿用现有功能的部分，列在 §10。

## 1. 背景与目标

现在打开 Hermesh，第一步就是在浏览器里登录，不登录进不了主窗口。用户还不知道产品能做什么，就被要求登录。

hermeshd 已经支持不登录运行（提交 90769b8f「单机模式」）：本机的 Agent 提供方、项目、任务和 Her 都能在不连服务器的情况下工作，之后可以原地升级到账号。界面还没有接上。

本期目标：

1. **打开就能用**：新用户不登录，也能接入本机的 Agent 提供方、开启 Her、接上模型、开始工作。
2. **先看到能力，再决定登录**：启动流程按「本机 Agent → Her → Hermesh 网络」的顺序介绍产品，登录放在最后，并且可以跳过。
3. **登录有明确的理由**：只在用到需要账号的功能时提示登录，并说明原因。
4. **启动流程有仪式感**：粒子、撒花、功能演示动画，墨黑配色，与官网一致。
5. **账号页更清楚**：把「怎么连」（账号）和「连了什么」（设备、agent、其他电脑）分开，并为以后的扫码直连留好位置。

## 2. 范围

**本期做**

- 新的首次运行流程（§5），替换现有的「登录 → 准备本机 → 连接 agent → 第一个任务」。
- 主窗口：未登录状态、需要登录的入口提示、个别文案（§6）。
- 设置 › 账号与设备：重新布局；新的「添加设备」表单；退出登录后保留本机（§7）。
- 墨黑配色用于首次运行窗口（§4）。

**本期不做**

- 扫码直连（§9 只定义它在界面上的位置）。
- iPhone 的首次运行。
- 同时连接多个服务器。
- 命令行 agent 在未登录时接入本机。

## 3. 概念与用语

用户需要理解的概念只有下面这些。其他技术词（管理密钥、认领码、连接地址、核对码）只在用到的那一步出现。

| 概念 | 界面上的说法 | 含义 |
|---|---|---|
| 未登录 | 未登录 | 打开就是这个状态。Her、本机的 Agent 提供方、项目和任务都能用 |
| 账号 | Hermesh 账号 | 让这台电脑接入 Hermesh 网络的方式。官方服务叫「登录」，自己的服务器叫「连接」 |
| 网络 | Hermesh 网络 | 一张专为 AI Agent 搭的通信网：手机、电脑和各家 Agent 两两互通 |
| 设备 | 设备 | 能查看任务、给 Agent 派活、批准连接请求的 iPhone 或电脑（现有的「可信设备」） |
| 其他 agent | 云端助手和其他 agent | 通过 MCP 或 CLI 接入的 ChatGPT、Grok Bot 等 |
| 其他电脑 | 其他电脑 | 现有的「环境」，Her 和 agent 用它们上面的 Agent 提供方 |

**称呼**：界面上称 Her 一律用「Her」，不加引号；必须用代词时用「它」，不用「她」。本期改动的文案见 §6.4。

**平台用语**：下文以 Mac 为例。Windows 和 Linux 沿用现有的平台变体：「这台 Mac」→「这台电脑」，「Touch ID」→「Windows Hello」/「系统密码」。

### 4.4 动效

| 名称 | 规格 |
|---|---|
| 标准缓动 | `cubic-bezier(.2,.8,.2,1)` |
| 换页 | 旧内容 160ms 内透明度到 0、缩放到 .985；180ms 后放入新内容（窗口尺寸同时变化时为 520ms） |
| 进场 | 带进场标记的元素从「透明、下移 14px、模糊 6px」到正常，700ms 标准缓动；延迟 = 序号 × 80ms + 额外延迟 |
| 表单出现 | 遮罩 200ms 淡入；表单 350ms 从上方 10px、缩放 .98 落下 |
| 弹出 | 对勾等小图标：从缩放 .3、透明到正常，500ms，`cubic-bezier(.3,1.6,.5,1)` |
| 逐字出现 | 每个字延迟 55ms，300ms 从透明、模糊 4px 到正常 |
| 减弱动态效果 | 系统开启「减弱动态效果」时，所有动画、过渡、粒子、撒花、循环演示全部关闭；逐字出现的文字直接完整显示；演示停在第一帧 |

## 5. 首次运行

### 5.1 何时出现

| 情况 | 打开后看到 |
|---|---|
| 新安装，从未完成首次运行，未登录 | 首次运行第 1 步 |
| 首次运行中途退出 | 回到退出时那一步（第 1 步除外：从第 1 步重来） |
| 完成过首次运行（无论是否登录） | 主窗口 |
| 升级前已经登录或加入过的用户 | 主窗口，永远不显示首次运行 |
| 这台设备是「仅执行任务」的电脑（machine only） | 主窗口，和现在一样 |
| 已退出登录 | 主窗口（未登录状态），不再显示首次运行 |
| 被其他设备移除 | 现有的「这台 Mac 已不在你的 Hermesh 账号里」页，不变 |
| 「全部清空」之后 | 首次运行第 1 步，上方显示现有的清空说明（ErasedNote），原型未画 |

### 5.2 窗口与贯穿各步的元素

- **窗口**：沿用现有首次运行窗口尺寸 720×660（最小 720×600）。标题栏只有红绿灯，高 44。
- **页面区**：内容水平居中，左右内距 56（第 3、4 步为 44）。第 3、4、5 步内容垂直居中，底部留 20。
- **底栏**：高至少 66，内距 `14 24 20`。没有「上一步」。
- **进度条**：窗口最顶端一条 2px 线，品牌光 0→1→2 渐变，右端圆角 2。宽度：第 1 步 5%、第 2 步 28%、第 3 步 52%、第 4 步 76%、第 5 步 100%，变化时 900ms 标准缓动。进入主窗口后消失（500ms 淡出）。
- **背景极光**：两团直径 460px、模糊 80px 的光，第一团品牌光 0，第二团品牌光 2。整体每 12 秒在 ±12px 内往返漂移。每步的位置和强度（强度基数 0.20）：

  | 步骤 | 光 1 | 光 2 |
  |---|---|---|
  | 1 欢迎 | 偏移 (−70, −110)，缩放 .8，强度 1× | (80, −60)，.8，1× |
  | 2 Agent 提供方 | (−300, −300)，1，0.7× | (320, 260)，1，0.5× |
  | 3 Her，未接上模型 | (−40, −230)，.6，0.5×，颜色 `#b3bcf2` | (50, −200)，.6，0.5×，颜色 `#ffa3be` |
  | 3 Her，已醒来 | (−90, −190)，.95，1×，`#b3bcf2` | (100, −170)，.95，0.9×，`#ffa3be` |
  | 4 登录，未登录 | (−260, −60)，1，0.6× | (260, −60)，1，0.6× |
  | 4 登录，已登录 | (−200, −40)，1.1，1× | (200, −40)，1.1，1× |
  | 5 完成 | (−150, −120)，1.15，1× | (150, −100)，1.15，1×，`#ffa3be` |

  偏移相对窗口中心；位置变化 1.5s 标准缓动，强度和颜色变化 1.2s。
- **背景光点**：34 个白色圆点，半径 0.6–1.5px，基础透明度 .15–.5，按正弦缓慢闪烁（相位每帧 +.02，透明度在基础值的 55%–100% 之间）；每帧水平 ±.06px、向上 .05–.2px 漂移，飘出顶部后从底部随机位置重新出现。只在首次运行窗口出现。

### 5.3 第 1 步：欢迎

### 5.5 第 3 步：Her

### 7.4 退出登录

点「退出登录…」弹出提示框：图标人像；标题「要退出登录吗？」；正文「这台 Mac 上的项目、任务和 Her 都会保留。其他设备和 agent 将无法连接这台 Mac。」；主按钮「退出登录」、普通按钮「取消」。

确认后：

- Toast「已退出登录」。
- 这台 Mac 回到未登录状态：页面变为 §7.2 的未登录样子；主窗口左下角显示「未登录」。
- 正在跑的任务不中断，Her 继续工作，项目和任务保留。
- 这台 Mac 仍是这个账号的设备，它的密钥保留。其他设备、云端助手和其他电脑连不到它，在它们那边显示为离线。
- 其他电脑、其他设备和已连接的 agent 不在这台 Mac 的列表里显示，重新登录后恢复。

现在的「退出登录」要求先在另一台设备上移除这台设备，本期改为上述行为。被其他设备移除的情况仍走现有的「已不在你的账号里」页。

### 7.5 再次登录

退出登录后点「登录」：

- 原来是官方服务：打开浏览器表单（§5.6.3 第 1 步）。浏览器里需要登录原来的账号；登录后直接恢复，不再出现授权表单，不需要 Touch ID。Toast「已登录」。
- 原来是自己的服务器：不打开浏览器，按钮变为「正在登录…」，连上服务器后恢复，Toast「已连接自己的服务器」。原型未画。
- 浏览器里登录了另一个账号：提示「这台 Mac 属于另一个 Hermesh 账号。请用原来的账号登录。」，按钮恢复。原型未画。
- 期间被其他设备移除：恢复后进入现有的「已不在你的账号里」页。

## 8. 状态与边界

| 情况 | 处理 |
|---|---|
| 首次运行中退出应用 | 下次打开回到那一步；第 3 步回到未接上模型的状态（Her 保持开启） |
| 第 2 步检查超过 20 秒仍无结果 | 查找中状态结束，按已回来的结果显示；没回来的按现有「正在检查…」显示在行内 |
| 第 3 步 Her 启动失败 | 选择模型区标题显示现有的 Her 启动错误说明，三个按钮不可点；「稍后设置」可用 |
| 登录过程中关闭首次运行窗口 | 和现在一样，浏览器登录可以在下次打开时继续（现有 `signInPending`） |
| 未登录时收到通知类请求 | 不会有：未登录时没有连接请求 |
| 已登录后服务器长时间连不上 | 现有连接提示条；左下角仍为「已登录」 |
| 退出登录时有任务在跑 | 不打断，不额外提示 |
| 这台设备是唯一的设备并退出登录 | 允许；账号保留在服务器上，重新登录即恢复 |
| 主窗口打开时首次运行未完成（升级中途） | 不会发生：首次运行未完成时只显示首次运行窗口 |

## 11. 决定

2026-11-25 由实施者按推荐定下（负责人授权）：

1. **墨黑只用于首次运行窗口及其表单**。主窗口和设置窗口跟随现有外观设置。理由：首次运行是品牌时刻，固定配色才能保证与官网一致；主窗口是每天用的工作界面，用户已选的外观（含浅色）不应被覆盖。
2. **授权页不再显示三个开关**，取默认值：成为可信设备、共享本机 Agent、提醒开启（提醒在 §5.8 生效，可在设置 › 通用、通知、这台 Mac › 保持在线中改）。「仅执行任务」的加入方式不再由桌面应用发起；只执行任务、不批准的电脑，改用命令行安装 hermeshd（不装桌面应用，现有方式，见 hermeshd.md），它天然就是这种身份。已经是这种身份的桌面应用不受影响。理由：首次运行只问一个问题；公司电脑是少数情况，现有命令行路径已覆盖。
3. **左下角只显示「已登录 / 未登录」**。服务器连不上由现有的连接提示条说明。理由：账号状态和连接状态是两件事，后者已有更醒目的提示。
4. **称呼 Her 用「它」**，只改应用内文案（§6.4），官网另行处理。理由：负责人此前指出 Bot 宜用「它」或直接称 Her。

## 12. 验收标准

1. 新安装后打开，不登录走完 5 步，进入主窗口，Her 能用接上的模型回复，并能在本机项目里启动 Claude Code 或 Codex 的任务。
2. 第 4 步选「暂不登录」后，主窗口和设置里需要登录的入口全部弹出 §6.2 的提示框；不需要登录的功能全部可用。
3. 第 4 步登录官方服务、连接自己的服务器、加入已有的 Hermesh 三条路径都能完成；完成时第 3 步启动的 Her 任务不中断。
4. 加入已有的 Hermesh 时只按一次 Touch ID（Her 已开启的情况下也是）。
5. 设置里退出登录后，正在等待回答的任务仍可在这台 Mac 上回答并完成；Her 仍能回复；iPhone 上这台 Mac 显示为离线。再次登录官方服务不需要 Touch ID，iPhone 上恢复在线。
6. 每一步的文案、尺寸、颜色、动效与本文一致；系统开启「减弱动态效果」时没有任何动画和粒子。
7. 升级前已登录的用户升级后直接进入主窗口，不出现首次运行。
