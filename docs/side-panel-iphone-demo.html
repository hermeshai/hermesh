会话里的文件 · iPhone 原型

和 Mac 的侧边面板同一套概念，按 iPhone 的习惯落地：直板屏推入页面，iPhone Duo 横放展开时是对话旁边的一列标签页。两台设备都可以点。

思路

概念和 Mac 一致：一个文件一个页面（文件 / 网页两类），项目文件有固定入口，目录树可以在文件旁边。形式按屏幕来，不按设备：窄屏推入页面，宽屏是对话旁边的一列。

1. 直板 iPhone：推入页面，树在底部抽屉
  • 会话顶栏右边不加按钮：项目文件留在 ⋯ 里（第一项），顶栏保持简洁。
  • 点回复里的文件 → 推入文件页；点 .html → 推入网页页。返回手势回到对话。
  • 顶栏胶囊：文件页只写文件名（所在文件夹在底部抽屉条上，不重复）；网页页没有抽屉，下面一行是所在文件夹；附件是 附件 · 大小。
  • 文件页右上：源码（Markdown、SVG）、⋯（分享…、复制路径）。网页页右上：⋯（分享…、复制路径）。
  • 目录树抽屉：文件页底部常驻一条「项目文件」玻璃条，点一下（或上拉）升起半屏的树，当前文件高亮、所在文件夹已展开。在树里点文件，就在这个页面换成它（对应 Mac 的「在当前标签打开」），抽屉落回底部；点 .html 推入网页页。网页页没有抽屉，和 Mac 网页标签没有目录树一致。
  • ⋯ 里的项目文件仍是一层一页的列表，文件带大小；它是从对话进入的完整浏览。
  • 版本条（第 N 轮结束时的版本 / 查看当前版本）浮在抽屉条上面。
2. iPhone Duo 横放：侧边面板
  • 顶栏右边换成侧边面板按钮（和 Mac 同一个右侧栏图标）。打开时，左侧菜单自动收成图标栏，把宽度让给面板。
  • 面板：一排可横滑的标签（玻璃胶囊，当前标签带关闭）、＋（系统菜单：项目文件），最右边放大 / 缩小：放大时面板占满菜单以外的整页，对话让开；缩小回到并排。
  • 文件标签的目录树：右边一列，默认收起，用工具栏的目录树按钮打开；在树里点文件，就在当前标签打开。
  • 网页标签：地址 + ⋯（分享…、复制路径）。
  • 竖放展开、合上（外屏）都按窄屏走：推入页面 + 抽屉。
3. 两种形态都有
点到的打开
图片（回复的、自己发的）全屏大图查看器，不变
Office、音视频、压缩包Quick Look（在文件页里），不变
自己发的 .html、.md 等附件网页页 / 文件页（现在是 Quick Look，网页不运行）
待你确认
  1. 抽屉落下时只留一条「项目文件」：还是只留一个小把手、更省地方？
  2. 在抽屉里点文件后，抽屉自动落回底部（看文件）；需要连续翻几个文件时要再拉起。要不要改成停在半屏？
  3. 附件里的 .html 在网页页里运行：附件是单个文件，页面引用的同目录文件读不到。
