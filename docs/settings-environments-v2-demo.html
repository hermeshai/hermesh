设置重构 v2 · 环境

在方案 C 的基础上精简：「编码 agent」改名为「Agent 提供方」（AgentProvider）；项目不再绑定到提供方，在环境下单独管理；环境页只留入口和开关，说明文字尽量短。

和上一版方案 C 比，改了什么

  • Agent 提供方 新：原来叫「编码 agent」，指 Claude Code、Codex、Gemini CLI 这些在环境里真正干活的程序。连进来调用的 agent（Cursor、OpenClaw…）仍然在「授权」里。代码里本来就叫 provider，中英文就对上了。
  • 项目独立 新：项目只属于环境，不再选「给哪些提供方用」。现在后端的规则是 agents 为空就表示「全部」，所以新建项目不填这个字段就行。要限制某个 agent 能用哪些提供方，用授权里已有的「Agent 提供方」范围。Agent 提供方的页面只保留登录状态和默认模型。
  • 环境页只有三组：入口（Agent 提供方、项目、Her、磁盘目录），访问（共享、暂停），这台 Mac 特有的后台服务。运行中的任务数放进标题下的状态行，点击就跳到主窗口。
  • 侧栏 新：账号放在最上面（和 macOS 系统设置一样），然后是通用、授权，最后是「环境」分组，加号在分组标题上。
  • 磁盘目录更精简：顶部一个总量和「释放空闲的」按钮，下面是按大小排序的列表，最后是自动清理开关。去掉了分色条和分组切换。
