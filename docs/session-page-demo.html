会话页 · 原型

iPhone · 两处会话页（SessionView、ThreadPage）共用同一套顶栏和对话行

定稿：这一版做什么

1 · 顶部：双行玻璃胶囊，点一下出任务信息

标题变成居中的 Liquid Glass 胶囊，第二行是 环境/项目，和左右按钮同高。点它打开原来 ⓘ 的「任务信息」面板，面板内容不变。右侧只留 ⋯，ⓘ 去掉。

2 · 去掉「你」

你发的消息不再有标签，右侧蓝色气泡就是你。标题副行的「你 ·」也去掉。

3 · Agent 派的活：灰气泡 + 角标

灰色气泡，左上角压派活者的头像：Her 是小猫，授权 Agent 用它自己的 logo（这里是 Grok），没有 logo 的用首字母（和 Agent 列表里的头像同一套）。按每一轮标：Her 派的任务里你插的话仍是蓝色。

4 · 去掉结尾那句话

「这一轮做完了…」整行删除，进行中的「思考中 / 处理中」保留。
