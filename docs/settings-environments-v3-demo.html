设置重构 v3 · 按 macOS 系统设置的方式

按苹果「系统设置」的组织方式重新编排：每个页面讲一件事，开关说清楚后果，偶尔才用的操作做成按钮放在页面底部，储存空间仿照「通用 › 储存空间」。标 新 的需要新开发。

按苹果的思路做了哪些决定

  • 侧栏分三段：最上面是账号（和 Apple ID 的位置一样）；然后是只管这个 App 的「通用」「通知」「授权」；最后是「环境」，每个环境一项。「通知」从「通用」里拆了出来，每页都更短。
  • 环境页像「关于本机」：居中显示图标、名称和一个状态胶囊（在线 · 2 个任务运行中，点击去主窗口）。下面只有两组：保持在线这一个开关，加上四个入口（Agent 提供方、项目、Her、储存空间）。名称做成「名称」行里可以直接改的输入框，和 macOS「通用 › 关于本机 › 名称」一样。
  • 不用「⋯」菜单：苹果的设置页几乎不用隐藏菜单。偶尔才用的操作是页面底部的按钮：左边是会造成后果的「停用这台 Mac…」（像「退出登录…」的位置），右边是「复制诊断信息」「暂停接受新任务」。暂停后页面顶部出现横幅「已暂停接受新任务 · 恢复」。
  • 保持在线 新：合并了「登录时打开」「退出后保持后台服务」「后台服务 启动/停止」三项。开关下面的说明直接写后果。服务停了，状态胶囊会变成「后台服务已停止 · 启动」。
  • 项目：用 macOS 常见的表格，底部带 + / −（像「登录项」）。点一行选中，− 移除；每行右边是「独立 worktree / 原地」的弹出菜单。项目不再绑定 Agent 提供方。
  • 储存空间：仿照 macOS「储存空间」：最上面一条按项目分段的条形图；中间是「建议」，有「自动释放 新」和「释放空闲的工作目录 新」，各带一个「开启…/释放…」按钮；下面按项目列出，ⓘ 打开一个表格，可以选中多个工作目录一起释放。不能释放的那一行变灰，并写明原因。用 GB（1000 进制），和 Finder 一致。
  • 高级信息收进表单：账号页底部是「退出登录…」和「高级…」，服务器、身份 ID、接入命令和「全部清空…」都放进「高级…」打开的表单里。

还要定的

  • 「磁盘目录」改叫「储存空间」，和 macOS 的叫法一致。
  • 拆出「通知」页，侧栏会多一项，可以接受吗？
  • 远程环境（vps-1）的储存空间要等 hermeshd 加远程统计接口，demo 里显示「暂不支持」。
