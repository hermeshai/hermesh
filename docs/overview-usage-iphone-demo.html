页面怎么分的

  • 概览：只讲现在，三段各管一件事。叠卡是等你处理的，一次一件；链路图是全部，线不分状态，点节点看经过它的全部任务；下面是进行中和最近完成。首页不放数字。
  • 统计页：侧边菜单里概览下面的一项，导航栏上「用量 / 额度」两段。导航栏右边只放得下一个按钮：再多一个，「正在连接」那条状态就没法居中了。
  • 用量：上面是筛选，下面是指标。筛选全是下拉菜单：时间范围，加 Agent 提供方、环境 / 项目、发起方三个。项目属于环境，所以两者是一个菜单：选环境，或选某个环境里的某个项目。指标一个一张卡：任务、Token、近 18 周。加维度是多一个菜单，加指标是多一张卡。
  • 额度：每个提供方两个窗口，还剩多少、什么时候重置。

统计项回答的问题放在哪数据现状代价

按项目、按环境 新展示花在哪个项目、哪台机器用量的筛选QueryWork 已支持这两个分组，没有界面在用只做界面
和上一周期比 新展示比之前多了还是少了用量手机留着 130 天的数，多问一段就有只做界面（30 天的对比要 60 天，够）
各提供方剩余额度、重置时间 新数据还能用多少，该把活派给谁额度；快用完时进「需要你处理」Codex 和 Claude Code 运行时都会报（5 小时、每周窗口的已用比例和重置时间），现在被丢掉了小：环境记下每个提供方最近一次上报，随环境状态带给手机；不存历史

想请你定的

  • 「查看全部」到一个单独的任务页，还是拉开侧边菜单。这份列表今天在侧边菜单的「任务」一栏。Demo 里做成了单独的页。
  • 刚开始时，叠卡里放「开始使用」的下一步。现在的 App 里「开始使用」是首页上单独的一段，四步都列出来。放进叠卡后只显示下一步；代价是看不到四步的全貌。
  • 空状态的画法。能做点什么的地方用虚线框加一句蓝色入口，做不了什么的地方只有居中两行字，没有图标和插画。如果你想要更有存在感的空状态（比如一张小图），告诉我方向。
  • 图上的虚线框「+ 连接 agent」「+ 添加环境」少于三个时出现，和桌面端一致。如果你觉得手机上不该在图里放入口，可以只留真实的节点。
  • 手机上原来的流向图不留了，由链路图代替：两张图说的是同一件事，一张是现在，一张是累计。累计的那份数在「用量」里用发起方和 Agent 提供方两个筛选能查到。如果累计的图也想留，它可以作为「用量」里的第四张卡。
  • 维度菜单里的小字。每个选项下面带这段时间的任务数和 token，用来代替页面上的排行。如果你觉得这也算把指标和维度掺在一起，可以去掉，菜单就只剩名字。
  • 时间范围从分段控件改成了下拉菜单。和现在的概览不一样了；切范围从点一下变成点两下。
  • 额度按提供方分。同一个提供方在两台环境上可能是两个账号，Codex 报账号 ID 可以合并，Claude Code 不报。Demo 里先按提供方画，写明是哪台环境报的。
  • 额度只在 Agent 运行时更新。很久没跑的提供方，数是旧的。要不要让环境定时去问一次，是另一个代价。
  • 设置里的「用量」移进「用量」页后，设置里不再留。
