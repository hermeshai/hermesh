新建会话与输入框

桌面端 · 第 2 版 · 可点击

这一版改了什么

  • 输入框：就是 Her 的输入框，一点没加。环境、项目、独立 worktree、模型、权限模式都在框外的一行。
  • 入口：侧栏 Her 上面一行「新建会话」（⌘N）。
  • 模型：一个面板，不再有层层弹出的子菜单。上面搜索，左边供应商，右边它的模型，底部一排思考强度。搜索时跨供应商列出结果。
  • 添加项目：项目菜单最后一项。先列出这台机器上最近的 git 仓库，也可以逐层浏览它的文件夹或直接输入路径，然后定项目名和工作方式。
  • 按项目分组：组头右侧有 ＋，在这个项目里新建会话（底部「侧栏分组」切换）。
添加项目用到的后端

浏览远程机器的目录不需要新接口：机器端已有 ListRepos（主目录下的 git 仓库）和 ListFolders（逐层列文件夹，带是否仓库、分支），iPhone 的「添加项目」已经在用，桌面端现在只能手输路径。这里的文案取自 iPhone 那一版。

和现在代码不一样的两处

① 换环境时，新机器上有同名项目就保留，没有才回到「临时工作区」（现在是一律回到临时工作区）。② 组头的 ＋ 用这个组里最近一个任务所在的机器。

还没放的

编码 / 规划、模型的其他参数（Extended Thinking、Fast Mode）、中途引导、单次会话的基准分支（用项目的默认基线）。
