侧边面板：标签页 · Mac 原型

工具栏固定两个按钮；侧边面板按标签页组织，回复里的文件点一下开一个标签。可直接点窗口里的文件标签、按钮和标签页。

这一版定下的东西

只搭骨架：工具栏两个固定按钮，侧边面板改成标签页，原来的预览弹窗收进标签页。不加新的功能。

1. 工具栏右端
  • 信息面板：环境和上下文卡片，按钮一直在原位，图标换成 ⓘ（应用里已有的 info 图标）。侧边面板开着时不能展开（按钮变灰）；打开侧边面板会收起信息卡片。
  • 侧边面板：展开或收起右侧面板，固定在最右边，和左上角的侧栏按钮对称。
  • 后台任务按钮照旧，只在有后台任务时出现（原型里没有后台任务）。
2. 侧边面板 = 标签页
  • 标签栏：每个标签一个图标、名称、关闭；末尾 ＋ 新建标签页；右端只有 放大 / 还原（占满侧栏以外的窗口）。
  • 标签栏下面一行是这个标签自己的工具栏，每种标签自带。
  • 每个会话各自记住自己的标签（现在的文件面板就是这样）。关掉最后一个标签，面板收起；面板空着打开时，先开「项目文件」。

4. 点回复里的文件
文件现在改后
网页预览弹窗新的网页标签
Markdown、SVG、PDF预览弹窗新的文件标签，目录树关着
代码、文本、带行号的文件面板新的文件标签，定位到行，目录树关着
图片大图查看器，不变
Office、音视频、压缩包Quick Look，不变

从回复里点：已经开着的就切过去，没开的开新标签。在目录树里点：就在当前标签里打开，像浏览器在当前页跳转，目录树保持开着；只有 .html 例外，它是网页标签，单独开一个。预览弹窗（含「铺满窗口」）去掉，由面板的放大代替。

已定
  • 信息面板和侧边面板互斥：侧边面板开着时，信息面板展开不了。
  • 信息面板换成 ⓘ 图标，和侧边面板的图标分开。
  • 网页标签先只有地址和「在浏览器中打开」；后退、前进、刷新等做内置浏览器时再加。
  • 目录树里点文件，在当前标签打开。
