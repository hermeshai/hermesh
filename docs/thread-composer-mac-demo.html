和 iPhone 同一套，改了什么

  • 框下面那行去掉。工作目录、模型、权限模式都不再在框下面。
  • 设置收进框里。框是空的、没在打字时只有一行：＋、文字、发送。点进框（或按任意键开始打字）展开成两行，底部一行：＋、模型、思考强度、停下、发送。框里有字或附件时不收起。
  • ＋ 是一个菜单。「添加附件…」（Mac 上照片也是文件，和现在一样直接选文件）；下面「权限模式」四档，带说明，超过上限的置灰。权限模式只在这里，框上不显示。「规划」（先出方案）去掉了。
  • 思考强度单独一个按钮，点开是这个模型的档位，不用再进模型面板。没有档位的模型不显示。
  • 模型面板改成一列。现在是左边供应商、右边模型两栏；改成按供应商分组竖着排，每行一个模型，选中的只有一个勾；未安装、已停用的不列；底部的思考强度去掉。搜索照旧。
  • 工作目录、分支，两个按钮，在框上方（参考你截的图）。只有 git 仓库的项目才有。左边「当前目录 / 独立 worktree」；右边分支：独立 worktree 时是「基于 main」，从哪个分支开（默认是仓库的默认分支，可以「从远程开始」）；当前目录时是它要工作的分支（默认已签出的，选别的会在开始前切过去）。
  • 分支面板：搜索；独立 worktree 时有「从远程开始」开关；列表里已签出的在最前标「当前」，默认分支标「默认」，被别的 worktree 签出的标「worktree」（当前目录模式下不能选）。会话自己的 hermesh/… 不列。要补的后端和 iPhone 版说明一致：列分支时说出默认分支和被 worktree 占用的；「从远程开始」先 fetch；当前目录模式切分支（目录不干净就拒绝）；新分支默认从默认分支开。
会话页
  • 同一个框；运行中多一个停下，发的消息进「待执行队列」。
  • 框下面原来的「work-mac · fresh-app」挪到标题右边（灰字）；Mac 的标题栏现在没有这个，信息面板关着时就看不到在哪跑了。
  • 审批卡片、待执行队列的样子和位置都不变，在框上方。
要你定的一处

Mac 上新会话打开时框会自动获得焦点（现在就是这样，方便直接打字），所以一打开就是展开的。要初始页更简洁，可以改成不自动获得焦点、按任意键才进框；原型里先按「不自动」做。
