用量分组 · iPhone

iPhone 用量视图加分组后的样子，和 Mac 已实现的分组一致，按手机重新摆过。屏幕里都能点：时间范围、分法、筛选按钮（点了会轮换几个状态）、图例、柱子。右上角可以切「项少 / 项多」的数据。

概览

顶部两行

  • 第一行：实时｜用量｜额度。第二行：分法，然后是时间范围和一个筛选按钮。平时只有这两行。
  • 分法放最左：这一行里最常点、面积最大的控件。时间和筛选挨着放在右边：两个都是「看哪些数据」，是一组。
  • 分法是「合计｜按 Agent｜按环境」，先整体再拆分，默认按 Agent。选了某个环境（或只有一个环境有数据）时，「按环境」变成「按项目」。
  • 筛选按钮点开是系统菜单：Agent 提供方、环境 / 项目、发起方，各自再点进去选，和现在环境 / 项目的两级菜单是同一种。
  • 有筛选时才多出一行：按钮变成强调色并带上个数，下面列出生效的筛选，点叉去掉；这一行可以横滑。
  • 「实时｜用量｜额度」不挪进导航栏：导航栏中间留给连接状态那一行。

图表和明细

  • 明细在指标卡里排两列：最多 3 项各一色，其余合成灰色的「其他 N 项」，点开就地列出；两张卡一起展开、收起。
  • 点某一项，两张图里只留它，再点一次恢复；不改筛选。
  • 柱子高 72pt（现在是 56pt），一根里要分四段；三种分法一样高。
  • 点按柱子，上方弹出那一天的总数和各项的数。这是 iPhone 现在没有的交互。
  • 环境 / 项目两级：先按环境分；筛选里选了某个环境就按它的项目分。

实现时要处理、demo 里看不出的

  • 按住横扫选柱子：30 天时一根柱子只有 8pt 宽，点不准；按住左右滑动选中手指下的那一根，和系统的图表一样。
  • 大字号：系统字号调到辅助功能档时，两列放不下，图例改成一列。
  • 旁白：每张图读出总数和各项；图例每格读「Claude，23 个任务，37%」。
