设置重构 · iPhone

和 Mac v3 同一套结构，按 iOS「设置」的写法落地：账号在最上面，然后是应用设置，最后是「环境」列表，每个环境一页。标 新 的需要新开发。

怎么看

手机里的内容都能点：账号、通知、外观、授权、每个环境；环境里面有名称、Agent 提供方、项目、Her、储存空间；还能暂停和移除。左滑项目或工作目录可以删除或释放。

和 Mac 的不同

iPhone 不是环境，所以没有「保持在线」和「停用这台 Mac」。iPhone 看到的每个环境都在别的设备上，所以储存空间统计全部依赖远程接口（Mac 上只有远程环境需要）。

和现在的 iPhone 比，改了什么

  • 入口改名为「设置」：现在点头像打开的表单叫「账号与设备」，里面却装着全部设置。改成「设置」，最上面是账号卡片，点进去才是「账号与设备」（可信设备、退出登录、全部清空、删除账号）。
  • 「机器」不再是单独的一页：环境直接列在设置里，和 Mac 侧栏的「环境」分组对应。「其他可信设备」从机器页挪到「账号与设备」。
  • 环境页：上面是图标、名称、系统和版本，加一个状态胶囊（在线 · 2 个任务运行中）。下面依次是：名称（点进去改，和 iOS「通用 › 关于本机 › 名称」一样）；四个入口；版本和更新；「暂停接受新任务」；最后是红色的「移除…」。暂停后，顶部出现横幅，可以直接恢复。原来的「接受新任务」开关和右上角菜单都去掉了。
  • Agent 提供方：原来叫「编码 agent」。每个提供方的页面保留登录说明、「测试」和默认模型，去掉了项目。没有安装的放在单独一组，每个带安装方式的链接。
  • 项目：从提供方下面拿出来，归在环境下。点进去可以改「工作方式」，或者「移除项目」；左滑也能移除。
  • 储存空间 新：和 iPhone 自带的「储存空间」一个样子：条形图，「建议」（自动释放、释放空闲的），按项目列出；点进项目，左滑一个工作目录就能释放。需要新的远程接口。
  • 外观改成单独一页，网络诊断和用量留在设置首页。

Mac 和 iPhone 的对应关系

Mac 侧栏iPhone 设置
账号（顶部）账号卡片 › 账号与设备
通用（外观、语言、更新）外观（语言和更新跟随系统和 App Store）
通知通知
授权授权（原来叫「连接的 Agent」）
环境 › 这台 Mac / vps-1 / …环境 › macbook-pro / vps-1 / …（没有「这台 iPhone」）
—用量、网络诊断（只有 iPhone 有）

还要定的
