设计规则

兼顾「并发工作台的空间恒定性」与「历史归档流的最近活跃查找」，不破坏现有的服务端游标分页。

置顶（Pin） 悬停行右侧一键点大头针、在 ⋯ / 右键菜单点「置顶」，或直接把任务拖到顶部置顶区均可置顶。推荐采用独立「置顶」分组置于列表最顶部：任务在运行、提问、跑完之间切换时始终留在原位（仅更新图标光环或状态圆点），真正作为跨天长线工作台；一个置顶都没有时整段不显示。协议层复用已有的 Session.pinned 字段，Mac 与 iPhone 天然同步。协议已有字段
进行中排序 默认按会话创建时间（created_at）排列（新创建的在前，也可在视图选项切最早在前）。运行期间无论内部调多少次工具、上报多少次 Token 或刷新 updated_at，列表位置绝对静止，彻底消除多会话并发时的「蛙跳」与误触。
手动拖拽排序 在「置顶」与「进行中」内，按住任意行上下拖动即可自定义先后顺序（无需常驻拖拽手柄污染视觉，点击仍是打开会话）。手动调整过的相对顺序优先于默认时间排序；新创建的任务插入顶部，其余已排好的任务相对次序保持不变。拖拽跨过「置顶」边界即自动置顶 / 取消置顶。
需要处理 · 已结束 继续按状态变更 / 本轮结束时间（updated_at）排列：谁刚停下来等你确认、谁刚报错、或者哪个三天前的老会话刚刚跑完最新一轮，都会排在对应分组最上方，不会沉底到历史旧分页里找不到。
唤醒老会话 当一个几天前的老会话发新消息重新进入「进行中」时：未置顶时按 created_at 落在「进行中」下方（因为进行中通常只有几个任务，一眼可见；若常盯可直接拖上来或一键 Pin 住），跑完后按最新 updated_at 回到「已结束」第一行。
视图选项菜单 保留右上角「分组 / 排序 / 显示」三段菜单；「排序」补齐「工作台默认（进行中按创建 · 其余按活跃）」、「创建时间」与「最后活跃」，当存在手动拖拽调整时提供「恢复默认顺序」。
