The first public release of the her CLI.

- An interactive mode in the terminal: `her`, `her "PROMPT"`, `her resume`
- `her exec` for scripts and CI, with one JSON result or an event stream, and exit codes that tell what happened
- `her serve` (JSON-RPC) and `her acp` (editors)
- `her login` for API keys, Token Plans, a ChatGPT subscription, a local model or your own compatible service
- Tools for files, commands, sub-agents, web search, workbooks; PDF, browser and computer use as components
- MCP servers and Skills
