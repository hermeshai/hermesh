The Qoder COSY protocol implementation references the Qoder plugin in yetone/magpie (MIT), which credits ufec/CLIProxyAPI (MIT). The legacy chat route (`src/qoder/legacy/`: the `Encode=1` body codec, the request body, the reply envelope and the model queue) references the Qoder plugin in magpie-community/plugins (`packages/qoder`, MIT), which ports the same protocol. The upstream notices are preserved here. The RSA public key is part of the client wire protocol, not an account credential.
