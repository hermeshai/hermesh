# Provider marks

The model providers' own marks, shown next to a provider's name on the console's
Models page. Taken from LobeHub Icons
(`@lobehub/icons-static-svg` 1.101.0, MIT, https://github.com/lobehub/lobe-icons),
with the size, style and title attributes removed. The marks are trademarks of
their owners and are used only to name their services.

| deepseek.svg | deepseek, deepseek-anthropic | deepseek-color |
| gemini.svg | google | gemini-color (its gradient ids carry `__uid__`, made unique per use) |
| kimi.svg | kimi | kimi-color |
| ollama.svg | ollama | ollama |
| openai.svg | openai | openai |
| openrouter.svg | openrouter | openrouter |
| qwen.svg | qwen | qwen-color |
| zhipu.svg | glm | zhipu-color |

Monochrome marks fill with `currentColor`, so they follow the theme.

Token Plan marks (same LobeHub version and license): `alibabacloud.svg` from
`alibabacloud-color`, `tencentcloud.svg` from `tencentcloud-color`, `volcengine.svg`
from `volcengine-color`, and `zai.svg` from `zai`. Zhipu Coding Plan reuses
`zhipu.svg`; both Ark products reuse `volcengine.svg`.
